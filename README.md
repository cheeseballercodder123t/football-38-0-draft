# Tactical Draft: 38-0 Football Sim

An ad-free, snappy, highly detailed football squad-draft and simulation game inspired by **82-0** and **38-0**, engineered to run smoothly on mobile and easily packaged into an Android APK via CapacitorJS.

---

## 🚀 Tech Stack

- **Framework**: React 19 (TypeScript) with Vite
- **Styling**: Tailwind CSS (mobile-first, sleek dark mode UI, cards, glow accents, authentic pitch grass texture)
- **Icons**: Lucide React
- **Packaging**: CapacitorJS (offline local storage, zero external APIs, zero ads)
- **Celebrations**: Canvas-Confetti for trophy galas and awards

## 🌟 Core Gameplay & Mechanics

### 1. Squad Draft & Reel System
- **11 Rounds**: Draft a starting XI (GK, DEF, MID, FWD) matching your chosen formation.
- **Historical Reel**: Each round spins an iconic squad and season from 1990 to present (e.g. *Arsenal 2003-04*, *AC Milan 2004-05*, *Barcelona 2010-11*, *Brazil 2002*, *France 1998*, *Real Madrid 2016-17*, *Manchester United 1998-99*, *Bayern Munich 2012-13*, *Inter Milan 2009-10*, etc.).
- **Tactical Rerolls**:
  - **1 FREE** tactical reroll per round.
  - Additional rerolls consume **Scout Tokens** (earned through hat-tricks, clean sheets, and trophy advancement).
- **Classic vs. Expert Mode**:
  - **Classic**: Complete transparency with all player attributes (OVR, PAC, SHO, PAS, DRI, DEF, PHY) visible.
  - **Expert**: Stats are hidden with `?` badges — test your authentic football knowledge!

### 2. Intangibles & "Aura" Engine
Ratings are not simple OVR checks. Players possess unique trait passives that dynamically influence the simulation:
- **"Titan's Roar"** (*Oliver Kahn, Peter Schmeichel*): Elevates all starting defenders with DEF < 83 up to 85. Suppresses opponent 6-yard box xG by 25%.
- **"The Enforcer"** (*Roy Keane, Gennaro Gattuso, Patrick Vieira*): Cuts opponent midfield possession by 12%, creates 2 counter-attack chances per game, +10% card chance.
- **"Raumdeuter"** (*Thomas Müller*): Increases partner striker shot conversion rate by +25%.
- **"92:48 Clutch"** (*Sergio Ramos, Didier Drogba*): +300% set-piece scoring chance in the 80th+ minute when trailing or tied in knockout matches.
- **"Metronome"** (*Zinedine Zidane, Andrea Pirlo, Xavi*): Team is completely immune to high-press stamina drain; passing completion locked above 90%.
- **"Solo Anarchy"** (*Ronaldo R9, Lionel Messi, Thierry Henry*): 20% chance per match to trigger a solo breakaway generating an isolated 0.85 xG shot.
- **"Sweeper Keeper"** (*Manuel Neuer*): Prevents 40% of opponent breakaways before they become shots.
- **"The Colossus"** (*Virgil van Dijk*): 100% 1v1 dribble stop rate; cuts opponent central box xG by 30%.
- **"Mind Games King"** (*Emiliano Martínez*): +50% penalty shootout save rate; stops high-xG 1v1 breakaways.

### 3. Tactical Rock-Paper-Scissors & Manager Perks
- **Tactical Matchups**:
  - **Gegenpress**: +15% counter-attack xG, smothers Tiki-Taka, but vulnerable to low-block counters.
  - **Tiki-Taka**: >60% possession, grinds down Low-Blocks, but vulnerable to fast direct transitions.
  - **Low-Block Counter**: Cuts opponent xG by 35%, generates high-quality breakaways against Gegenpress.
  - **Direct Vertical**: Versatile, high-tempo, attacks behind defensive lines.
- **Manager Perks**:
  - **Sir Alex Ferguson**: *"Fergie Time"* (+0.40 xG during 85'-95' if drawing or losing).
  - **Pep Guardiola**: *"Juego de Posición"* (+15% midfield possession control, +10% passing accuracy).
  - **José Mourinho**: *"The Special Low-Block"* (-40% opponent xG when leading after 60', lethal counters).
  - **Jürgen Klopp**: *"Heavy Metal Football"* (+20% high-press turn-over rate, +25% counter-press xG).
  - **Carlo Ancelotti**: *"The UCL Whisperer"* (+15% composure & finishing in knockout matches).

### 4. Expected Goals (xG) Simulation Engine
- **10-14 Possession Events**: Simulates real-time match flow based on midfield control and sector ratings.
- **Detailed Box Scores**: Minutes, Goals, Assists, xG, xA, Key Passes, Tackles Won, Saves, Clean Sheets, Yellow/Red Cards, and dynamic Match Ratings (6.0 - 10.0 scale).
- **Two-Legged Knockout Ties**: Home advantage (+8% attack buff), second-leg desperation (All-Out Attack past 60'), Extra Time (2x 15-min periods), and Composure-driven Penalty Shootouts.

### 5. Game Modes
1. **The Invincible 38-0-0**: 38-game league campaign aiming for an unblemished 38 wins and the Treble.
2. **Tournament Challenge**: Fast-paced UEFA Champions League knockout tree with 2-legged ties.
3. **Dynasty Mode**: Multi-season franchise where players age, veterans retire, youth wonderkids (*Lamine Yamal, Kobbie Mainoo, Arda Güler, Endrick*) are drafted, and trophy prize money is reinvested.

## 📱 How to Build and Run as an Android APK

The project is already pre-configured with Capacitor 8!

### Prerequisites:
1. [Android Studio](https://developer.android.com/studio) installed.
2. Android SDK (API 34+) and Java JDK 17+.

### Commands:

1. **Build and Sync Web Code to Android Assets**:
   ```bash
   npm run android:sync
   ```

2. **Open in Android Studio**:
   ```bash
   npm run android:open
   ```

3. **Build the APK in Android Studio**:
   - In Android Studio, select **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
   - The generated `.apk` will be in `android/app/build/outputs/apk/debug/app-debug.apk`.

4. **Direct CLI Run to Connected Android Device / Emulator**:
   ```bash
   npm run android:run
   ```
